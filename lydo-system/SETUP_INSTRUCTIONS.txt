┌──────────────────────────────────────────────────────────────────────────────┐
│                      ⚡ QUICK SETUP (5 MINUTES)                              │
└──────────────────────────────────────────────────────────────────────────────┘

  STEP 1: CREATE SUPABASE PROJECT
  ├─ Go to: https://supabase.com
  ├─ Click "New Project"
  ├─ Enter project name: "lydo-system"
  ├─ Choose region: (closest to you)
  ├─ Set database password: (save this!)
  └─ Click "Create new project" (wait 2-3 minutes)

  STEP 2: RUN DATABASE SCHEMA
  ├─ Open Supabase Dashboard → SQL Editor
  ├─ Click "New query"
  ├─ Copy content from: database/supabase_schema.sql
  ├─ Paste into SQL Editor
  └─ Click "Run" (takes ~20 seconds)

  STEP 3: GET YOUR CREDENTIALS
  ├─ Go to: Settings → API
  │  ├─ Copy: Project URL
  │  ├─ Copy: anon/public key
  │  └─ Copy: service_role key
  │
  └─ Go to: Settings → Database
     ├─ Copy: Host (db.xxxxx.supabase.co)
     └─ Have ready: Database password (from Step 1)

  STEP 4: CONFIGURE SYSTEM
  ├─ Edit: shared/supabase_config.php
  │  ├─ Line 10: SUPABASE_URL = 'https://xxxxx.supabase.co'
  │  ├─ Line 11: SUPABASE_KEY = 'your-anon-key'
  │  ├─ Line 12: SUPABASE_SERVICE_KEY = 'your-service-key'
  │  ├─ Line 18: SUPABASE_DB_HOST = 'db.xxxxx.supabase.co'
  │  └─ Line 22: SUPABASE_DB_PASS = 'your-db-password'
  │
  └─ Edit: shared/config.php
     └─ Line 10: define('USE_SUPABASE', true);

  STEP 5: ENABLE POSTGRESQL
  ├─ Edit: C:\xampp\php\php.ini
  ├─ Find: ;extension=pdo_pgsql
  ├─ Remove semicolon: extension=pdo_pgsql
  ├─ Find: ;extension=pgsql
  ├─ Remove semicolon: extension=pgsql
  └─ Restart Apache (XAMPP Control Panel)

  STEP 6: TEST
  ├─ Open browser: http://localhost/LYDO/lydo-system/test_supabase.php
  ├─ Check: All tests should show ✓ PASS
  └─ If any fail: Review config in Step 4

  STEP 7: LOGIN
  ├─ Open: http://localhost/LYDO/lydo-system/login.php
  ├─ Email: admin@lydo.gov.ph
  ├─ Password: Admin@1234
  └─ Should redirect to dashboard

┌──────────────────────────────────────────────────────────────────────────────┐
│                      🆘 TROUBLESHOOTING                                      │
└──────────────────────────────────────────────────────────────────────────────┘

  ERROR: "Could not connect to server"
  ├─ Check: Supabase credentials in supabase_config.php
  ├─ Verify: Project is running in Supabase dashboard
  └─ Check: Internet connection

  ERROR: "Could not find driver"
  ├─ Edit: php.ini
  ├─ Uncomment: extension=pdo_pgsql and extension=pgsql
  └─ Restart: Apache

  ERROR: "Table does not exist"
  ├─ Check: Schema was run in Supabase SQL Editor
  ├─ Go to: Supabase → Table Editor
  └─ Verify: 18 tables exist

  ERROR: "INSERT returns 0"
  ├─ Use: insertAndGetId($pdo, $sql, $params)
  └─ See: query_helper.php for examples

  TESTS FAILING
  ├─ Run: test_supabase.php
  ├─ Check: Which specific tests fail
  └─ Review: Error messages shown
